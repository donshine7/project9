# Eval Grader 프로젝트 규칙

이 프로젝트는 Runner가 고정한 실행물만 독립 채점한다.

- `graders/`, `rubrics/`, `baselines/`는 이 프로젝트에만 둔다.
- 후보 구현과 Runner 실행물은 읽기 전용으로 취급한다.
- manifest와 DB·Vault·출력 해시가 다르면 의미 채점 전에 실패 처리한다.
- 결정적 검사를 먼저 실행하고, 의미 평가는 사전에 고정된 rubric과 사람 보정 표본으로 수행한다.
- 실제 고객·사건·메일 데이터는 평가 보고서에 복제하지 않는다.
- 치명 오류는 평균 점수로 상쇄하지 않는다.
- 채점 중 후보 코드, DB, Vault, Runner 산출물을 수정하지 않는다.
