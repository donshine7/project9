# P261937-US 해외 특허 분류 보강

## 원인

- 기존 규칙은 `P261937-US`와 `미국출원`을 해외 단서로 인식했지만, 해외관리팀 참여자가 있을 때만 해외 사건을 확정했다.
- 따라서 외부 발신 또는 참여자 정보를 확정하지 못한 메일은 명시적인 국가 접미사가 있어도 해외 분기에 진입하지 못할 수 있었다.

## 수정

- `P`·`T`·`D` + 6자리 전체 관리번호에 국가 접미사가 있으면 해외팀 참여자와 무관하게 해외 사건으로 판정한다.
- `P261937-US`, `P211758-PCT-EP`, `P241750-RE-US`, `P262000-S1-JP`, `T261420-UA`, `D231154-JP`, `P261931-PCT`를 지원한다.
- `P241750-RE`, `P262000-S1`, `P241667-DIV1`처럼 국가 접미사가 없는 관계 접미사는 독립 해외 신호로 사용하지 않는다.

## 회귀 사례

- `[상상특허] P261937-US/주식회사 트리플닷 - 미국출원을 위한 "젤네일 제거용 화장료 조성물" 관련 명세서 초안 송부의 건` → `해외 특허`

- 프로젝트 원본·대시보드·정적 참고본·구조도·회귀 시험에 반영했다.
