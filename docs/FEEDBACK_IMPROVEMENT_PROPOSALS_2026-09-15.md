# 피드백·독립 검증 기반 개선안 (승인 대기)

## 적용 경계

이 문서는 개선 제안이며 운영 프롬프트·규칙·모델을 변경하지 않는다. 현재 고위험 검증은 계속 Sol/high다. 이번 관계·Action 반영 승인은 다음 개선안의 활성화 승인과 구분한다.

사용자가 새로 알려준 사실과 모델 오류를 분리한다. 디멘필의 회사/미정 분류, IRIMSO 주소의 고하정 귀속, 피지오 그룹의 10건 제한은 사용자 신규 근거다. 새 근거를 제공하기 전 모델의 답을 소급해 오답 처리하지 않는다. 자유문 요약의 오류는 독립 검증 결과이며 사용자 수정으로 위장하지 않는다.

## 제안 1 — 현재 작성문과 인용 이력의 구획

- 대상: `mail_intake` 입력 및 프롬프트의 후보 개정안.
- 원인: 현재 WORD 파일 추가 송부를 과거 A4 출력 안내로 요약한 사례, 현재 날인 회신과 과거 3건 요청 혼동.
- 제안: 원문을 보존하면서 문단 위치와 현재 작성문/인용문 후보 구획을 함께 제공하고, 각 요약 명제에 어느 구획을 사용했는지 반환하도록 한다. 헤더 탐지는 단서일 뿐 날짜·화자 확정 규칙으로 취급하지 않는다.
- 평가: 현재/인용 뒤바뀜, 전달 제목과 본문 날짜 충돌, 인용 없는 메일, 중첩 인용, 표가 포함된 메일. 새 후보가 현재 사실을 빠뜨리거나 과거 요청을 현재 Action으로 되살리는지 별도 채점한다.
- 상태: **제안**, 운영 미적용. 이번 요약 재작성은 기존 라우팅의 새 실행이다.

## 제안 2 — 사건별 귀속과 묶음 범위의 명시

- 대상: 요약·Wiki 처리 흐름의 후보 개정안.
- 근거 사용자 피드백: `policy-multiple-mail-links-20260914-feedback`, `user-cn-filing-types-2026-09-14-feedback`, `bc994cc0-cf85-467a-bb4d-f5b1762dcafc`.
- 제안: 요약마다 대상 사건과 범위(개별 사건/해당 사건을 포함한 묶음/귀속 불명)를 명시한다. 숫자 범위를 임의 확장하지 않고, 그룹 구성원이라는 이유로 모든 사실을 복사하지 않는다. 원출원 번호가 있다는 이유로 해외 출원인의 관계를 원출원에 상속하지 않는다.
- 평가: CN과 CN(PA) 구분, 범위 양 끝 사건, 시리즈 개별 사건, 묶음 계산서, 단일 날인 대상과 3건 정보확인, 피지오 고객 관계와 정부지원사업 구성원의 차이.
- 상태: **제안**, 운영 계약 자동 변경 없음. 이번 분리 배치는 명시적 대상 목록과 기존 독립 검증 게이트로 제한했다.

## 제안 3 — 사용자 확정 범위와 재분석 이력

- 대상: 피드백·품질 평가 흐름의 후보 개정안.
- 근거 사용자 피드백: `f5432676-b8bb-4388-92cb-c547c19cbd95`(디멘필 사업형태), `11668580-c3ca-471c-8f94-c30dc9c6375f`(고하정 주소), `bc994cc0-cf85-467a-bb4d-f5b1762dcafc`(그룹 범위).
- 제안: 사용자 확정값의 적용 대상·필드·유효 범위를 별도 표시하고, 이후 재분석 후보와 기존 후보를 대체 관계로 연결한다. 과거 후보·검증·사용자 피드백은 삭제하지 않는다. 현재 새 후보가 있다는 사실을 과거 반려 후보의 승인으로 취급하지 않는다.
- 평가: 같은 메일의 새 판단, 다른 사건으로 범위 확장 차단, 회사 명칭 별칭과 법적 형태 분리, 피드백 시각이 같은 경우의 최신 답변, 신규 Action 이후 오래된 Wiki 게시 차단.
- 상태: **제안**, 사용자 피드백과 `decision_comparison`의 오류 분류·평가 적격성을 자동 변경하지 않았다.

## 평가 및 승인 절차

1. 사용자 피드백의 당시 입력 스냅샷과 최종값을 연결한다. 신규 근거·일회성 예외·표현 선호는 모델 정오 평가에서 제외한다.
2. 독립 검증 사례는 별도 검증 세트로 보존한다. 사용자 정답 세트와 합쳐 정확도를 부풀리지 않는다.
3. 후보 프롬프트/흐름 버전으로 같은 입력을 재실행하고 기존 버전과 비교한다. 기일·사건번호·담당자·범위는 각각 평가한다.
4. 기존 중요 사례의 퇴행이 없고 사용자 승인을 받은 버전만 활성화한다.
