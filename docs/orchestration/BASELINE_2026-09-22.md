## 변경 소유권과 통합 위험

다음은 파일 경로와 기존 작업 범위로 정한 통합 소유권이다. 개별 과거 작업의 상세 보고가 아니라 checkpoint 이후 적용할 규칙이다.

| 범위 | 주 담당 | 공용 충돌 지점 |
|---|---|---|
| `easypat-automation/**` | EasyPAT | dashboard adapter, source priority, 안전 정책 |
| 통지 다운로드·responses | 대응 업무 | local-api, work-db, migration, 공용 UI |
| specifications | 명세서 업무 | local-api, work-db, migration, 공용 UI |
| 분석·Wiki·업무 갱신 | 총괄/해당 기능 | analysis 계약, work-db, agent config |
| `.gitignore`, package/lock, layout/CSS, migration 번호 | 총괄 | 모든 구현 작업 |

단계 2부터 공용 파일은 총괄이 변경 순서를 예약한다. migration은 현재 012 다음 번호를 각 worktree가 임의 선점하지 않는다.

EasyPAT에 남은 주요 범위는 국내사건 업로드 readback·서로 다른 실제 PDF 교차검증, 일부 첨부 경로 일반화, HTTPS 본문 캡처 조건 확인이다. 실제 시스템을 사용하는 검증은 별도 승인을 받아야 한다.
