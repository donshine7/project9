# EasyPAT HTTPS 자동화 범위와 안전 기준

## 목적

EasyPAT이 사용하는 HTTPS 통신을 분석하여 사건 조회, 문서 목록 확인, 파일 다운로드와 정보 추출을 마우스 이동 없이 자동화한다. 대상은 사용자가 접근 권한을 가진 회사 EasyPAT 계정과 데이터로 한정한다.

## 1단계 허용 범위

- 로그인 및 세션 유효 여부 확인
- Windows 자격 증명 관리자를 이용한 자동 로그인
- 당소관리번호 전체 문자열의 정확 일치 검색
- 사건 상세정보와 진행사항 조회
- 문서 목록 조회
- 사용자가 지정한 폴더로 문서 다운로드
- 화면 결과와 HTTPS 응답의 읽기 전용 대조

현재 단계에서는 서버 데이터를 생성·수정·삭제하지 않는다.

## 강제 안전 기준

1. 자동 로그인용 사용자명과 비밀번호는 사용자가 별도 등록한 Windows 자격 증명 관리자에서만 읽는다. 평문 설정 파일, 소스 코드, 명령행 인자, 로그 또는 LLM 입력으로 전달하지 않는다.
2. 자동 로그인은 한 번만 시도한다. 실패, CAPTCHA, 추가 인증, 계정 잠금 경고 또는 예상하지 못한 화면이 나타나면 반복하지 않고 중단한다.
3. 세션 쿠키와 인증 헤더는 필요한 경우 현재 프로세스 메모리에서만 일시적으로 사용하며 파일, 로그, 오류 메시지 또는 LLM 입력에 남기지 않는다.
4. TLS 인증서 검증을 끄지 않는다. Fiddler 인증서는 통신 규격을 확인하는 개발 과정에서만 사용한다.
5. 허용된 HTTPS 호스트·포트·경로 외에는 요청을 보내지 않는다.
6. LLM이나 사용자 입력으로 받은 임의 SQL을 실행하지 않는다. 서버 규격상 SQL 형태가 포함되더라도 검증된 고정 업무 함수 내부에 감추고 허용된 매개변수만 바인딩한다.
7. 조회 결과의 당소관리번호는 접미사를 포함한 전체 문자열로 검증한다. `-CN`과 `-CN(PA)`, `-S1`과 `-S2`를 서로 병합하지 않는다.
8. 응답 형식이 예상과 다르거나 세션이 만료되면 자동 로그인은 최대 한 번만 시도하고, 그 결과도 불명확하면 중단한다.
9. 다운로드는 기존 파일을 덮어쓰지 않으며 파일명, 크기, 형식과 SHA-256 해시를 검증한다.
10. 수정·저장 기능은 별도 단계에서 사용자의 작업 시점 승인을 받는 이중 단계 방식으로만 활성화한다.
11. 검증된 고정 SQL 원문은 현재 Windows 사용자 범위 DPAPI로 암호화한 `.local/templates/*.dpapi` 파일에만 보관한다. 평문 파일·로그·명령행 인자로 기록하지 않고 복호화 후에도 등록 지문을 확인한다. 암호화 파일은 Git에서 제외하며 기존 파일은 덮어쓰지 않는다. 동일 Windows 계정에서 실행되는 다른 프로그램에 대한 격리 수단으로 간주하지 않는다.
12. 업무 조회 클라이언트는 알려진 비밀번호·토큰 계열 열이 나타나면 전체 결과 반환을 거부한다. 인증 규격 조사용 스키마 검사기는 행 값을 반환하지 않는다. 이 열 이름 검사는 모든 개인정보나 임의 별칭의 비밀정보를 탐지하는 완전한 분류기가 아니므로 고정 요청 검증을 대체하지 않는다.
13. 인증 템플릿에는 사용자명과 비밀번호를 저장하지 않는다. 캡처에서 입력 위치만 안전한 표식으로 교체한 템플릿을 DPAPI로 보호하고, 저장 전후에 고정 지문과 입력 위치 수를 다시 확인한다.
14. 인증 어댑터는 실제로 검증된 최초 로그인 성공 경로만 런타임에 제공한다. 실패 응답 의미와 세션 갱신은 별도 검증 전까지 비활성으로 유지하며, 프로세스 수명 동안 자동 로그인을 한 번 넘게 시도하지 않는다.
15. 고정 조회 템플릿은 캡처 요청 지문만으로 사건에 결합하지 않는다. 같은 캡처 흐름의 응답에서 접미사를 포함한 전체 당소관리번호가 정확히 일치해야 하며, 불일치가 발견되면 운영 지문과 사건 바인딩을 즉시 제거한다.

## 감사 기록

기록할 수 있는 항목은 작업 종류, 당소관리번호, 시작·종료 시각, 성공 여부, 로그인 시도 결과(성공·실패만), 응답 스키마 버전, 다운로드 파일의 경로·크기·해시이다. 사용자명, 인증 헤더, 쿠키, 비밀번호, 원본 SQL과 전체 응답 본문은 기록하지 않는다.

## 단계 종료 조건

- 기계 판독 정책 파일이 허용 엔드포인트와 작업을 제한한다.
- HTTPS가 아닌 요청, 허용되지 않은 호스트·작업, 쓰기 작업과 임의 SQL이 코드 수준에서 거부된다.
- 민감한 메타데이터가 로그 출력 전에 제거된다.
- 관련 자동 테스트가 모두 통과한다.
