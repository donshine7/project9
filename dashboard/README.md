# 상상특허 로컬 운영 대시보드

`대시보드 실행.cmd`를 더블클릭하면 기본 브라우저에서 대시보드가 열립니다. 실행 중인 명령 창을 닫으면 로컬 서버도 종료됩니다.

## 운영 갱신 원칙

업무 자동화 정책이 바뀔 때 다음 항목을 같은 작업에서 함께 갱신합니다.

1. 실제 실행 코드와 Outlook 연결 상태
2. `dashboard-data.js`의 규칙·폴더 데이터
3. `index.html`의 운영 지표·변경 이력·로드맵
4. 상위 `docs/architecture.mmd`의 전체 구조

대시보드는 현재 로컬 정적 운영판입니다. Outlook 메일을 직접 읽거나 외부로 전송하지 않습니다. 자동 집계는 다음 구현 단계로 분리되어 있습니다.
