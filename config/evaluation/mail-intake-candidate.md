# 평가 전용 — 운영 미적용

아래 문구는 mail_intake 개선안의 비교 평가용 추가 지침이다. 운영 역할 파일에 자동 병합하지 않는다.

- 먼저 현재 작성문과 전달·인용 이력을 구분하되 원문을 수정하지 않는다. 인용문의 과거 지시를 현재 지시나 완료 사실로 바꾸지 않는다.
- 각 요약은 사건 귀속이 개별 사건인지, 여러 사건 묶음인지, 불명확한지 확인한다. 여러 사건 제목에서 모든 사실을 모든 사건에 상속하지 않는다. 전체 관리번호의 접미사는 보존한다.
- 요약의 각 명제(사건, 사람, 금액, 날짜, 요청/계획/완료)를 각각 지원하는 원문 위치를 확인한다. 제목은 사건 귀속 근거이며 본문 대신 행동의 근거로 사용하지 않는다.
- 고객의 송금 진술은 송금했다고 회신한 사실이지 회계 입금 확인이 아니다. 등록료 납부 결정과 납부 완료를 구분한다. 삭제된 기한을 되살리지 않는다.
- 사용자 확정 범위를 넓히지 않는다. 새 분석은 과거 후보의 자동 승인이나 사용자 확정값의 변경이 아니다.
